주
상품 발주처 현재고 미출고 7일 판매 14일 추이 소진 예상 기준(주) 적정재고 상태 발주 권장
판정 기준 — 판매속도는 최근 7일 일평균 발주수량. 가용재고 = 정상재고 − 미출고 주문. 적정재고 = 각 상품의 기준주(기본 6주) 판매량. 발주 필요: 가용재고 ≤ 적정재고(소진 기준주 이내). 주의: 기준주 ~ +3주. 발주 권장수량: 적정재고 − 가용재고. 소진 예상이 발주처 리드타임 안쪽이면 빨간색으로 표시됩니다.
데이터 출처: 이지어드민 [재고관리 > 현 재고조회]의 정상재고·접수, [일자별 재고조회]의 일별 발주수량(최근 14일).

현재 상태—
GitHub 토큰넣으면 모든 기기(휴대폰·PC)에서 같은 발주처 정보를 봅니다
토큰이 없으면 이 브라우저에만 저장됩니다. 여러 기기에서 쓰려면 한 번만 설정하세요:
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate
  2. Repository access: stock-dashboard 만 선택
  3. Permissions → Contents: Read and write
  4. 만든 토큰을 위 칸에 붙여넣고 저장
주의: 저장소가 공개(Public)라서 저장한 suppliers.json(발주처 연락처 포함)도 주소를 아는 사람은 볼 수 있습니다.
